# WattPath

![wattpath](https://github.com/user-attachments/assets/07db0a72-75dc-4a28-8337-bdd4f066ee23)

WattPath is a modern scheduling tool for Waterloo (and other?) students.
Very early build! Mostly UI at the moment.

### Building/running
Install requirements: `npm install`

Run the app: `npx run expo start`

Current only functional on desktop.
